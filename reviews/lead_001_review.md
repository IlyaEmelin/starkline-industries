# Review заявки lead_001

## Краткое резюме
Заявка от Starkline Industries описывает потребность фонда в небольшом помощнике для первичного разбора обращений инженеров и волонтёров после аварийных выездов. Боль понятна: детали теряются в вечерней переписке, а утром координатору неясно, кому перезванивать и какие данные нужно уточнить.

## Оценка качества заявки
Заявка понятна по организации, боли и желаемому результату. Уже ясно, что фонду нужен помощник для первичного разбора обращений: он должен читать входящую заявку, кратко оценивать полноту, выделять недостающие данные и сохранять review для координатора. Для передачи в работу заявка пока неполная.

## Что уже понятно
- Организация: Starkline Industries.
- Сфера: ремонт общественных мастерских и учебных лабораторий.
- Нужен помощник для первичного разбора обращений после аварийных выездов.
- Уже есть таблица типов заявок.
- Уже есть список частых вопросов от волонтёров.
- Уже есть общий почтовый ящик фонда.
- Уже есть один координатор, который разбирает обращения вручную.

## Недостающие данные
- Контакт для связи и кто принимает решение.
- Сроки запуска или желаемый дедлайн.
- Приоритет задачи.
- Бюджет или допустимый диапазон бюджета.
- Точный объём автоматизации: только review, маршрутизация, уведомления, статусы или интеграции.
- Каналы поступления заявок: только почта/форма или ещё мессенджеры, таблицы, телефонные записи.
- Ограничения по данным: персональные данные, доступы, хранение, кто может читать заявки.
- Ответственный человек со стороны клиента за согласование правил и проверку результата.

## Безопасный следующий шаг
Не передавать заявку команде как готовый brief. Сначала запросить у ответственного контакт, сроки, приоритет, бюджетный диапазон, границы автоматизации, каналы поступления заявок и ограничения по данным, затем обновить review для Томаса и координатора.
